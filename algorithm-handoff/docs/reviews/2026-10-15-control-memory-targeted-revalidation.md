## 关键检查

- `storyAndProfileProduced=true`
- `derivedSourcesExcludeControls=true`
- `canonicalWriteCount=0`
- 6/6 `status=completed`

- 本轮不是独立 24 轮质量评估，不用于替代负责人对追问、等待、音色和内容质量的判断。

T6 的可见回复仍是达到访谈追问深度后的自然停顿确认：

> 后来在阳台种花这段先停在这里也可以。您还愿意继续讲吗，还是今天先到这里？

这是本轮实际返回的 InterviewPolicy 行为；故事和画像在异步结果中分别展示。它不等于该轮体验已经获得认可：用户请求整理故事时，主回复却询问是否继续，二者的协调性仍需负责人评审。

## 本轮修复对应关系

1. 纯进入、换题、继续等操作语句在没有明确故事/画像要求时跳过 Memory 调用。
2. 混合了事实的输入仍进入 Memory 抽取，不因出现控制词而整体丢弃事实。
3. 具体的 `life_event_detail` 可以作为故事来源；一次性事件不会自动变成画像字段。
4. Memory 诊断按当前 `evidenceId` 关联，避免把上一轮结果显示到控制轮次。
5. 故事和画像分别成功或失败，互不阻塞主回复，也不写入正式 `CanonicalMemory`。
