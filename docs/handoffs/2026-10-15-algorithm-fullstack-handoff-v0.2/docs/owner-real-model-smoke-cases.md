# 负责人真实模型体验用例（candidate/pre-human）

这份清单用于负责人在真人访谈前做一轮真实模型体验。它不是正式的人体研究，也不把个人体验自动当成统计结论。建议每个用例只测一次，保留原话、AI 回复、等待时间、音频是否播放和页面截图；不要为了挑选最好的一次而重复抽样。

## 1. 体验前检查

1. 打开算法工作台，不要直接打开 `/api/algorithm/v0.1/health`；后者只返回机器 JSON。
2. 记录 `/health` 和 `/version` 的 `buildId`、`apiVersion`、`interviewPolicyVersion`。
3. 确认测试主体是虚构案例或内部成年人扮演，不录入真实老人隐私、健康、财产或家庭冲突信息。
4. 每轮开始前记录输入方式：文字、电脑麦克风或手机麦克风。
5. 每轮结束后打开 `view`，观察本轮 Memory、故事草稿、画像草稿和 Shadow 诊断。

## 2. 固定场景

| 编号 | 输入示例 | 观察重点 |
|---|---|---|
| C1 日常聊天 | “今天下雨，我在家听了一会儿收音机。” | 是否自然承接，不强行进入访谈；回复是否不模板化 |
| C2 明确进入访谈 | “我愿意聊聊以前在纺织厂工作的日子。” | 是否得到明确同意后进入正式访谈；是否只问一个有价值的问题 |
| C3 追问 | “那时候我每天很早就出门。” | 追问是否围绕已说线索，是否没有凭空补事实 |
| C4 想不起来 | “具体是哪一年我想不起来了。” | 是否允许不确定，不把记不清解释为认知问题 |
| C5 换题 | “这段先聊到这里，我们说说孩子吧。” | 是否尊重换题；旧主题不应继续追问 |
| C6 暂停/继续 | “我有点累，先停一下。”随后“继续吧。” | 是否先暂停，明确继续后再恢复；不会自动保存或结束 |
| C7 不保存 | “这段不要记下来。” | 是否停止对应保存/复用；回复不能声称已保存 |
| C8 形成草稿 | “请把刚才关于纺织厂的内容整理成一篇温和的故事，也给我看看画像。” | 故事和画像是否分别生成；内容是否贴近原话，未说内容不被补写 |
| C9 短语音 | 说：“嗯，我以前在厂里上班，后来调到了质检。” | ASR 是否去掉明显填充词但保持事实；短文本规整不应改变原意 |
| C10 播放中打断 | AI 开始读回复时立即说“等一下，我想补充一句。” | 音频是否停止、旧生成是否取消、新输入是否进入正确轮次 |
| C11 失败恢复 | 暂时断开网络后再次提交同一幂等键 | 是否返回可理解状态；重试不会重复写入或产生两条结果 |
| C12 结束 | “今天先到这里。” | 是否结束当前会话；旧句柄不能继续写入 |

## 3. 每轮按同一张表评分

每项 1～5 分，1 表示明显不可用，3 表示可用但需改进，5 表示本轮体验良好。另写一句证据，不只填分数。

| 维度 | 要问自己什么 |
|---|---|
| 对话自然度 | 回复是否像在回应这句话，而不是套模板？ |
| 追问价值 | 问题是否帮助老人继续讲，是否只问一个问题？ |
| 事实和 Memory 准确度 | 记下的内容能否在原话中找到连续依据？有没有把请求误当成长期偏好？ |
| 故事/画像可用性 | 是否忠于原话、平白温和、没有擅自添加经历？ |
| 等待与语音 | 等待是否能接受，ASR、TTS 是否清楚，失败是否有提示？ |
| 打断 | 新输入开始后，旧音频和旧回答是否真正停止？ |
| 安全和意愿 | 是否尊重不保存、暂停、换题和敏感信息边界？ |

## 4. 体验通过的最低门槛

- 没有把虚构推断说成老人明确说过的事实；
- 没有未经确认声称“已经永久保存、删除或分享”；
- “我听清楚了”只在确实需要确认时出现，不能每轮固定出现；
- 每轮最多一个主要问题，问题必须和上一句有关；
- 追问、换题、暂停、结束和不保存都能被用户理解；
- Memory 至少显示原文依据和状态，故事与画像失败时互不拖垮；
- 播放中打断能停止旧音频，或清楚告诉用户本轮没有完成；
- 遇到失败不无限等待，重试不造成重复写入。

体验后请把“用例编号、原话、AI 回复、分数、最满意处、最需要修改处”交回算法侧。只有反馈归档并完成修复复验后，才进入正式版本冻结。
